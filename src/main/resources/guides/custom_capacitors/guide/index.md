# Custom Capacitors

This mod lets you create capacitor tiers beyond Octadic. The `level` value controls how powerful your capacitor is. Higher means faster machines and more energy storage.

## Config vs KubeJS

With config, you can apply color tinting on the base texture.

With KubeJS, you can use completely custom textures.

## How to Add Capacitors

1. [Config File](config.md): Edit the TOML config and restart game
2. [KubeJS](kubejs.md): Use scripts for modpack integration
